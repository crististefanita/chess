# Chess Lab 0.16.2

## Pe scurt

Această corecție aliniază titlul Analizei partidei cu celelalte antete și întărește recepțiile native de audit.

## Îmbunătățiri

- **Analiza partidei:** titlul Web rămâne lângă Înapoi la dimensiune compactă și text mărit.
- **Istoricul partidei cu AI:** sanity-ul nativ compară eticheta mutării selectate cu cursorul comun, inclusiv după reluare.
- **Salvate și Încheiate:** recepțiile native au un ID comun; Extent respinge fazele lipsă, înlocuite sau nepotrivite.
